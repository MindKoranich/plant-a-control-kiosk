# PLANT A CONTROL — Tomato Kiosk (2 pages)

โปรเจกต์นี้เป็นหน้าจอ Kiosk ขนาด 800×1280 สำหรับระบบควบคุมการปลูกมะเขือเทศ แยกเป็นไฟล์ HTML/CSS/JS พร้อมเปิดใน VS Code

## โครงสร้างไฟล์

```
plant-a-control-kiosk/
├── index.html          หน้าหลัก Kiosk (ต้นมะเขือเทศตรงกลาง + สถานะการเติบโต + To-Do รายวัน)
├── info.html            หน้าข้อมูลเพิ่มเติม Kiosk (กราฟ & เป้าหมาย EC/pH, ขั้นตอนปฏิบัติ, อุปกรณ์, ข้อควรระวัง)
├── admin.html           แผงควบคุมผู้ดูแลระบบ (Admin Console) ป้องกันด้วยรหัสผ่านสำหรับแก้ตัวเลข/ค่าทั้งหมด
├── data/
│   ├── kiosk-data.json  จุดศูนย์กลางสำหรับแก้ไขข้อมูลทั้งหมด (ปุ๋ย, เซนเซอร์, งาน SOP, อุปกรณ์, ข้อควรระวัง)
│   └── README.md        คู่มืออธิบายโครงสร้างและการแก้ไขไฟล์ JSON ละเอียดทุกส่วน
├── css/
│   ├── home.css         สไตล์เฉพาะหน้าหลัก
│   ├── info.css         สไตล์เฉพาะหน้าข้อมูลเพิ่มเติม
│   └── admin.css        สไตล์เฉพาะแผงควบคุม Admin
└── js/
    ├── home.js                  ตรรกะหน้าหลัก (นาฬิกา, สลับ stage, checklist, โหลด JSON & LocalStorage)
    ├── info.js                  ตรรกะหน้าข้อมูลเพิ่มเติม (สลับ stage/แท็บ, checklist, โหลด JSON & LocalStorage)
    ├── admin.js                 ระบบจัดการผู้ดูแลระบบ (ล็อกอิน, ฟอร์มแก้ค่า, บันทึกทันที, ดาวน์โหลด/คัดลอก JSON)
    ├── tailwind-config-home.js  ธีมสี/ฟอนต์ Tailwind ของหน้าหลัก
    └── tailwind-config-info.js  ธีมสี/ฟอนต์ Tailwind ของหน้าข้อมูลเพิ่มเติม
```

## สิทธิ์การแก้ไขข้อมูล (Admin vs Kiosk)

- **หน้าตู้ Kiosk สำหรับเกษตรกร (`index.html`, `info.html`):**
  - แสดงผลข้อมูลตัวเลขทั้งหมดแบบ **อ่านอย่างเดียว (Read-only)** ป้องกันการกดแก้ไขโดยไม่ตั้งใจ
  - เกษตรกรสามารถติ๊กเครื่องหมายถูก (✓) ที่ To-Do งานประจำวันได้เท่านั้น
  - มีปุ่มทางลัด **[🔒 Admin]** เล็กๆ ที่แถบหัวหน้าจอเพื่อเปิดหน้าจัดการ
- **แผงควบคุมผู้ดูแลระบบ (`admin.html`):**
  - มีระบบล็อกอินป้องกัน: รหัสผ่านเริ่มต้นคือ `admin` (หรือ PIN `1234`)
  - สามารถแก้ไขค่าเป้าหมายและค่าปัจจุบันทั้งหมดได้:
    - ค่า EC, pH, อุณหภูมิ, ความชื้น RH, แรงดึงการคายน้ำ VPD
    - จำนวนวันในรอบปลูก, วันที่ปัจจุบัน, ร้อยละความคืบหน้า
    - งานประจำวัน (To-Do) และขั้นตอนปฏิบัติงานมาตรฐาน (SOP 4 สเต็ป)
    - รายการอุปกรณ์ที่ต้องใช้ พร้อมคุณลักษณะ
    - ข้อควรระวังและแนวทางแก้ไขฉุกเฉิน
    - เกณฑ์ประเมินคุณภาพผลผลิต 4 ด้าน
  - **บันทึกเข้าตู้ Kiosk ทันที (Real-Time Sync):** เมื่อกดปุ่ม *"💾 บันทึกข้อมูลเข้าตู้ Kiosk ทันที"* ตู้ Kiosk ที่เปิดอยู่จะอัปเดตตัวเลขใหม่ทันทีโดยไม่ต้องโหลดหน้าซ้ำ
  - **ดาวน์โหลด / คัดลอก JSON:** มีปุ่ม *"📥 ดาวน์โหลด JSON"* และ *"📋 คัดลอก JSON"* นำไปใส่ไฟล์ `data/kiosk-data.json` ได้ทันที
  - **คืนค่าตั้งต้น:** มีปุ่ม *"🔄 คืนค่าเริ่มต้น"* เพื่อล้างข้อมูลที่บันทึกชั่วคราวกลับเป็นค่าโรงงาน

## การแก้ไขและอัปเดตข้อมูล (Data Configuration)

เมื่อต้องการเปลี่ยนข้อมูลในระบบ (เช่น ปรับค่าปุ๋ยเป้าหมาย, เปลี่ยนงานประจำวัน, เพิ่มอุปกรณ์, หรือแก้ข้อควรระวัง):
- **วิธีที่ 1 (ผ่านหน้าเว็บ Admin):** เข้าไปที่ `admin.html` ใส่รหัสผ่าน `admin` แล้วพิมพ์แก้ไขผ่านฟอร์มได้ทันที
- **วิธีที่ 2 (ผ่านไฟล์โค้ด):** แก้ไขที่ไฟล์ [data/kiosk-data.json](file:///Users/m/Downloads/plant-a-control-kiosk/data/kiosk-data.json) โดยตรง
- ศึกษาโครงสร้างและการปรับแต่งได้ที่ [data/README.md](file:///Users/m/Downloads/plant-a-control-kiosk/data/README.md)

## วิธีเปิดดู

ไม่ต้องติดตั้งอะไรเพิ่ม เพราะใช้ Tailwind CSS ผ่าน CDN:

1. เปิดโฟลเดอร์นี้ใน VS Code
2. ติดตั้งส่วนขยาย **Live Server** (แนะนำ) แล้วคลิกขวาที่ `index.html` → "Open with Live Server"
   หรือรัน `python3 -m http.server 8080` แล้วเปิด `http://localhost:8080`
3. ปุ่ม "หน้าหลัก" / "ข้อมูลเพิ่มเติม" ที่แถบล่างของทั้งสองหน้าจะลิงก์ไปมาระหว่างไฟล์จริง พร้อมซิงค์สถานะงานที่ทำเสร็จแล้วข้ามหน้าอัตโนมัติ

## หมายเหตุ

- ต้องต่ออินเทอร์เน็ตเพื่อโหลด Tailwind CDN และ Google Fonts
- ดีไซน์ยึดตามไฟล์ต้นแบบ (Stitch export) 2 หน้าที่แนบมา ปรับให้เป็นไฟล์แยกจริงและเชื่อมลิงก์กันแทนป๊อปอัปเดิม
